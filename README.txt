AMPLA CAPITAL WEBSITE
=====================

Files:
- index.html              Main website page
- ampla-logo.jpg          Ampla Capital logo
- hero-background.jpg     Hero image/background

INSTALLATION
------------
Upload all three files to the web root for:
  amplacapital.com
  www.amplacapital.com

Keep all three files in the same directory.

The site is static HTML/CSS and requires no database, WordPress, plugins,
server-side code, or content management system.

DOMAIN / EMAIL IMPORTANT
------------------------
The domain currently uses Microsoft 365 for email. Publishing this website
should NOT require changing Microsoft 365 MX, SPF, DKIM, autodiscover,
or other existing email-related DNS records.

If DNS changes are required to point the web domain to hosting, please
change only the web-hosting records required for the root domain (@)
and/or www. Do not remove or replace the Microsoft 365 email records.
